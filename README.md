# 音乐平台流行趋势预测

> 2025 珠海科技学院数学建模竞赛 B 题 · **二等奖**
> 基于音乐平台约 1,588 万条真实用户行为数据（原始 1.4 GB），完成「关键因素分析 → 推广策略优化 → 播放量预测」三段式建模

## 项目解决了什么

1. **什么决定一首歌火不火？** —— 统计检验 + 机器学习归因
2. **平台该把 50 个推荐位给哪些艺人？** —— 混合整数规划在业务约束下求解最优组合
3. **每位艺人未来 60 天的每日播放量是多少？** —— 时序特征工程 + 梯度提升模型递归预测

## 核心结果

| 问题 | 方法 | 关键结果 |
|------|------|---------|
| 一：关键因素分析 | ANOVA 检验、皮尔逊相关、随机森林特征重要性 | 下载量与播放量相关系数 0.95；「下载量 + 独立用户数」贡献约 91% 预测能力；测试集 MAE 0.0174（平均误差约 2.7%） |
| 二：推广策略优化 | 随机森林预测 + pulp 混合整数规划 | 在推荐位、性别比、语言比、每艺人 Top3 歌曲约束下求解最大化总预测播放量的艺人组合 |
| 三：播放量预测 | 滞后特征 + 滑动窗口、Optuna 30 轮调参、模型对比 | LightGBM（RMSE 139.13）优于 XGBoost（158.83），递归预测全部艺人未来 60 天每日播放量 |

## 复现说明

- **必须使用 pandas 2.x**（已锁定 2.2.3）：问题二的 `groupby.apply` 依赖旧版分组键行为，pandas 3.0 会报错，详见 requirements.txt 注释
- 问题一 ANOVA p 值与论文逐位一致；随机森林指标与论文偏差 <1%（库版本差异）
- 问题三代码注释中标注：LSTM 因原环境无 tensorflow 未参与最终对比，实际为 LightGBM vs XGBoost 两模型对比
